================================================================================
  OBSERVATIONS
================================================================================

1. THRESHOLD DETECTOR IS MORE ACCURATE
   Threshold detector total error: 0-0 across filters.
   ML detector total error: 2-2 across filters.
   The threshold detector uses scipy peak detection with separate L/R
   height thresholds and aggressive 0.5 Hz smoothing, which handles both
   tight and wide turns without per-run tuning.

2. FILTERS DO NOT AFFECT THRESHOLD DETECTOR TURN COUNTS
   All 5 filter variants produce identical turn counts with the threshold
   detector. This is because the detector applies its own 0.5 Hz Butterworth
   smoothing internally, which dominates any upstream filtering.
   Filters only affect speed estimates slightly (1-3 km/h variation).

3. FILTERS DO NOT AFFECT ML DETECTOR TURN COUNTS
   All filter variants produce identical turn counts with the ML detector.
